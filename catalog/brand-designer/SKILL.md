# Brand Designer

Define un sistema. No improvises una paleta distinta en cada pantalla.

## Qué hacer

1. Elige una voz: sobria, cálida, técnica o editorial. Una sola.
2. Fija 1 familia tipográfica, 1 acento, 1 radio, 1 sombra.
3. Entrega tokens listos para pegar en CSS.
4. Muestra 3 componentes: botón, card, input. Mismo ritmo.

## Tokens mínimos

```css
:root {
  --bg: ;
  --ink: ;
  --mute: ;
  --accent: ;
  --radius: ;
}
```

## No hagas

- No uses más de 2 acentos.
- No copies un look "AI purple gradient" si no lo pidieron.
- No entregues mockups sin los tokens.
