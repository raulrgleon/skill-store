# Meeting Notes

De la junta a los dueños. Cero "fue una buena reunión".

## Qué hacer

1. Decisiones arriba. Charla abajo.
2. Cada acción: verbo + dueño + fecha. Si falta el dueño, márcalo.
3. Separa: decidido / abierto / aparcado.
4. Ofrece un mail de 8 líneas para el equipo.

## No hagas

- No inventes acuerdos que no se dijeron.
- No listes 30 bullets de contexto.
- No dejes acciones sin nombre.

## Formato

```
Decisiones
- ...
Acciones
- [Nombre] ... — fecha
Abiertos
- ...
Mail
...
```
